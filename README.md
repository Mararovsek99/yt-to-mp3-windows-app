# YouTube Downloader

The fastest way to Download music from yt.
This app i made for friend, which is DJ, and he asked me if i can make app for him, to faster download music from yt.

So with lot of help with chatGPT i made this app.

With this program you can download one song, or entire playlist of 5000 songs if you need.

Compared to other apps, this is with no limit and has fastest download time per song.

## Features

- Download individual YouTube videos as MP3
- Download entire playlists
- Simple and easy-to-use interface
- Multi-language support
- Automatic link detection from clipboard
- Download progress and queue
- No Python or additional software required

## Download

Download the **latest release** from the **Releases** section of this repository.

1. Open **Releases**
2. Download the latest version
3. Extract the downloaded ZIP file
4. Run **YouTubeDownloader.exe**

That's it, no installation or additional setup is required.

## How to Use

1. Copy a YouTube video or playlist link
4. Choose whether you want to download a single video or a playlist
5. Click **Download**

Your audio will automatically be downloaded and converted to MP3 to prechosen location.

## About

YouTube Downloader uses **yt-dlp** and **FFmpeg** internally to download and process audio.

Everything required to run the application is already included in the release.

App have autoupdate. so when new verion is released, it will popup on screen, and you can update with few clicks.
